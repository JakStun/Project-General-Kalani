# Project-General-Kalani
Talking/moving bust of ST-series military strategic analysis and tactics droid of Confederacy

## Architecture Preview
User → Microphone → Raspberry Pi → Server → Response → Speaker

## Components (V1)
- Raspberry Pi 4
- RGB LED module 7 x NeoPixel WS 2812 (3x)
- INMP441 module I2S microfone
- GY-VL53L0X I2C Laser senzor
- Waveshare MG90S Micro Servo (2x)
